### Q1. Which job is the best fit to hand to an AI with light checking?

- A. Choosing the dosage of a medicine
- B. Deciding a court case
- C. Drafting a first version of a team update that you will read and edit
- D. Calculating payroll totals for 400 people

<details><summary>Answer</summary>

**Answer: C** - It is easy to check, useful even when imperfect, and cheap if wrong. The others are high stakes or need exact arithmetic.

</details>

### Q2. An assistant gives you a convincing link to a documentation page that turns out not to exist. What happened?

- A. The website was deleted overnight
- B. The model hallucinated - it produced a plausible-looking answer instead of saying it did not know
- C. Your browser blocked it
- D. The model was hacked

<details><summary>Answer</summary>

**Answer: B** - Models generate plausible text, not verified facts. Made-up citations and links are a classic hallucination.

</details>

### Q3. You ask about a tool released two weeks ago and get a vague, outdated answer. What is the most likely cause?

- A. The tool is not popular enough
- B. The model's training cutoff is before the release, and it did not search the web
- C. You asked in the wrong language
- D. AI cannot answer questions about software

<details><summary>Answer</summary>

**Answer: B** - A model only knows its training data. For recent facts, use a tool that searches and cites current sources.

</details>

### Q4. An AI wrote a database migration script for you. What should you do before running it in production?

- A. Run it immediately; AI code is tested
- B. Read it, understand it, and test it on a copy of the data first
- C. Ask the AI if it is correct and trust the answer
- D. Run it twice to be sure

<details><summary>Answer</summary>

**Answer: B** - High-stakes output always needs real verification. Asking the same model to grade itself is not a check.

</details>
