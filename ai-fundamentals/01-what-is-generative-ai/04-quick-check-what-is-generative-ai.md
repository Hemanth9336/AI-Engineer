### Q1. What makes generative AI different from traditional software like a calculator or a spellchecker?

- A. It follows exact rules a person wrote, just more of them
- B. It never makes mistakes because it was trained on so much data
- C. It runs faster than traditional software
- D. It generates new content from patterns it learned, instead of following preset rules

<details><summary>Answer</summary>

**Answer: D** - Generative AI learned patterns from huge numbers of examples and creates new content that fits them. Nobody wrote a rule for your specific request - and that is also why it can be confidently wrong, so B is false.

</details>

### Q2. You ask an email assistant for the same draft twice and get two different versions. What does that tell you?

- A. The tool is broken and should give identical output
- B. It is generating a fresh best guess each time rather than looking up a stored answer
- C. Someone changed the rules between your two requests
- D. The second draft is always the better one

<details><summary>Answer</summary>

**Answer: B** - Generating new content each time is normal for generative AI. Traditional software gives the same output for the same input because it follows fixed rules; generative AI does not.

</details>

### Q3. A chat assistant, a coding assistant, and a document summarizer all run on what underneath?

- A. Three completely unrelated technologies
- B. A spellchecker with a bigger dictionary
- C. A large language model - text in, text out
- D. An image generator that has been taught to write

<details><summary>Answer</summary>

**Answer: C** - Each product is a large language model with a different wrapper around it. Learn to work with an LLM once and the skill carries across all of them.

</details>
