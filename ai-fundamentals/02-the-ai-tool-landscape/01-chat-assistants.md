The tool most people meet first is a **chat assistant**: a web page or app with a message box. You type, it replies, you follow up. Under the hood each one is a large language model with a chat window, conversation history, and a few extra features bolted on.

## The big ones

| Assistant | Made by | Known for |
|---|---|---|
| **ChatGPT** | OpenAI | The one that started the wave; broad features, voice, image generation, custom GPTs |
| **Claude** | Anthropic | Strong writing and long documents, careful reasoning, coding |
| **Gemini** | Google | Tight links to Google Search, Gmail, Docs, and Android |
| **Microsoft Copilot** | Microsoft | Built into Windows, Edge, and Microsoft 365 |
| **Meta AI, Grok, Le Chat, DeepSeek** | Meta, xAI, Mistral, DeepSeek | Other serious options, several built on open models |

They all do the same core job - text in, text out - and for everyday tasks any of them will serve you well. The differences are in the details: how well each handles a very long document, which apps it plugs into, how it treats your data, and which underlying model you get on the plan you pay for.

## What they add around the model

A modern chat assistant is more than a raw model. Common extras:

- **File uploads.** Drop in a PDF, spreadsheet, or screenshot and ask about it.
- **Web search.** The assistant searches the web and cites sources, instead of relying only on what it learned in training.
- **Memory and projects.** It remembers preferences or keeps a set of documents attached to a workspace.
- **Voice.** Talk to it and hear it answer.
- **Model picker.** Choose a faster model or a more capable one for harder questions.

## AI search

A close cousin of the chat assistant is **AI search**: tools like Perplexity, Google's AI answers, and ChatGPT's search mode. You ask a question, the tool searches the web, reads the results, and writes a short answer with links. It is the right choice when the answer depends on recent facts - a release date, a price, today's outage - that a model could not have learned in training.

## Same engine, different wrapper

Keep the idea from the last topic in mind: these are LLMs with different wrappers. A skill you build in one - asking clearly, giving context, checking the answer - works in all of them. Next, the AI that lives inside the tools you already use at work.
