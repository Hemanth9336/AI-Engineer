### Q1. You need to know which version of a library was released last week. Which kind of tool is the best fit?

- A. A chat assistant with web search turned off
- B. An image generator
- C. An AI search tool or an assistant with web search, which reads current sources and cites them
- D. A spellchecker

<details><summary>Answer</summary>

**Answer: C** - A model only knows what it learned in training, so recent facts need a tool that searches the web and shows its sources.

</details>

### Q2. What is the main difference between Claude Code in the terminal and the Claude chat website?

- A. They use completely different kinds of AI
- B. Only the website can write code
- C. The terminal tool is free and the website is not
- D. The terminal tool can read files, run commands, and edit code on your machine as it works toward a goal

<details><summary>Answer</summary>

**Answer: D** - Both are LLMs underneath. The terminal assistant is an agent: it can take actions on your machine, asking before risky ones.

</details>

### Q3. You want to summarize a confidential customer contract. What is the safe choice?

- A. Paste it into whichever free assistant you use at home
- B. Take a screenshot so the text is not technically pasted
- C. Use the AI tool your employer has approved, on a business plan or API that does not train on your data
- D. Split it into small pieces across several free tools

<details><summary>Answer</summary>

**Answer: C** - Personal plans may use conversations for training. Approved business plans and the API come with a contract about your data.

</details>

### Q4. Why do the skills you learn in one chat assistant carry over to the others?

- A. They are all secretly the same product
- B. Every assistant uses the same model
- C. They are all large language models with different wrappers, so asking clearly and checking answers works everywhere
- D. They don't - each one needs a separate course

<details><summary>Answer</summary>

**Answer: C** - The wrapper changes, the engine does not. Prompting and verification skills transfer between tools.

</details>
