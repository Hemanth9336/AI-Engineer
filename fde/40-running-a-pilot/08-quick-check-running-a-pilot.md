### Q1. Why agree pilot criteria before starting?

- A. It's polite
- B. To make it longer
- C. Lawyers need it
- D. So the go/no-go decision is a reading of agreed numbers, not a debate of opinions

<details><summary>Answer</summary>

**Answer: D** - Upfront criteria depoliticise the decision.

</details>

### Q2. What four kinds of metric should a pilot cover?

- A. Speed, cost, tokens, uptime
- B. Users, sessions, clicks, pages
- C. Only accuracy
- D. Quality, adoption, safety and efficiency

<details><summary>Answer</summary>

**Answer: D** - Each catches a different way to fail.

</details>

### Q3. Which should trigger escalation to a human?

- A. A thumbs-up
- B. A question with an order id
- C. A short question
- D. The user saying 'this is unacceptable, I want to talk to someone'

<details><summary>Answer</summary>

**Answer: D** - Anger and explicit requests go to people.

</details>

### Q4. Adoption is high but most drafts get a thumbs-down. What does it suggest?

- A. The eval set misses what users actually need - mine the feedback for new cases
- B. Everything is fine
- C. Remove feedback
- D. More users

<details><summary>Answer</summary>

**Answer: A** - User feedback reveals eval gaps.

</details>
